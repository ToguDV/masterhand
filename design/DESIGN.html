01 · Foundations

Tokens

Every value below lives in design.css and is mirrored in DESIGN.md. Semantic tokens flip with the theme; the raw ramps stay put. Swap the three --font-* variables to change the whole voice of the system.

Color

Color themes

Settings > Appearance offers 13 color themes, each with light and dark variants. Light/dark stays an independent axis: the mode picks the column, the theme picks the row. Only color tokens change — layout, spacing and radii never do. Pick one to repaint this page:

theme-swatches · palette-gridclick to preview

Unknown stored values fall back to paper. Light accents are dark shades, dark accents are light shades.
